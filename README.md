# ResumeRanker
AI-powered resume ranking system built with Python and Flask.
## Features
- Upload multiple resumes
- Resume keyword analysis
- Experience detection
- Project detection
- Resume scoring
- Resume ranking
- User authentication
## Tech Stack
- Python
- Flask
- HTML
- CSS
- JavaScript
- PyPDF2
- python-docx
## How It Works
1. Upload resumes
2. Extract resume text
3. Analyze skills and keywords
4. Calculate scores
5. Rank resumes based on scores
## Future Improvements
- TF-IDF based matching
- Cosine similarity
- Job-description matching
- Advanced NLP
- Resume improvement suggestions
